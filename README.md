# Feedback Branding Studio

French branding studio website based in Marrakech, with Home, Work, Studio and Contact pages.

## Preview

Serve this directory with any static HTTP server, for example:

```sh
python3 -m http.server 3000
```

Open http://localhost:3000. No build or dependency installation is required.

## Structure

- `index.html`, `work.html`, `studio.html`, `contact.html`: site pages.
- `css/feedback.css`: Feedback branding and responsive adjustments.
- `css/main.css`, `css/plugins.css`, `js/`: retained Azurio template layout and animations.
- `img/generated/`: generated branding concept images and optimized crops.
- `fonts/`, `video/`: template media assets.

The portfolio projects ESSENCE, MAISON ATLAS and NOVA are illustrative concepts, not client references. Contact uses a mailto link. Google Fonts supplies the template typefaces.

Use of the original Azurio template assets remains subject to its license.
